## 4. 归因结论（按修正后协议）

### 用户提出的四个问题的回答

**Q1 传统物理信息本身能做到什么程度？**
物理组 P 单独即携带绝大部分可恢复信号：RNA **0.529**、PD bound **0.243**、PD unbound **0.200**。且 A9_Pcompact（660 维通道汇总）≈ A1_P（2,640 维）——P 的信息不来自维度堆砌。膜任务上所有组均不可泛化（LOPO 全≈0）。

**Q2 不依赖 Hodge 的 GSPH 高阶拓扑能做到什么程度？**
T 单独有真实但不强的信号：RNA **0.477**、PD bound **0.208**、PD unbound **0.118**——均显著高于规模控制（RNA S=0.130；注 PD bound S=0.219 与 T 相当，规模混杂严重）。但 **ΔT = P+T−P** 在三任务中分别为 **−0.026 / −0.023(p_holm=0.013，显著为负) / +0.001**——拓扑加入物理后**不产生增量，PD bound 上甚至显著有害**。

**Q3 Shared Hodge 单独提供多少信息？**
H 单独同样有真实信号：RNA **0.497**、PD bound **0.229**、PD unbound **0.136**。ΔH = P+H−P：**+0.017 / −0.010 / −0.013**，均不显著。**唯一接近的条件增量是 ΔH|T = P+T+H−P+T**：RNA **+0.033 [0.006, 0.060] p_holm=0.084**（边际）、PD bound **+0.024 [0.008, 0.042] p_holm=0.018**（显著）。

**Q4 拓扑+Hodge 加入物理后有无真正增量？**
ΔTH = A7−A1：RNA **+0.006**、PD bound **+0.001**、PD unbound **−0.008**——**三任务全部为 ~0 且不显著**。结论是：**GSPH 的预测能力主要来自 P（普通 patch 物理/几何统计），T+H 的净边际贡献 ≈ 0**。Hodge 仅在 T 已存在时显示微弱条件增量（PD bound 显著、RNA 边际），表现为 T∩H 之间的冗余而非与 P 的协同。

### 辅助证据
- **PD bound 规模混杂**：A8_S(22 个计数特征)=0.219 vs A7=0.244，full−size=+0.025 不显著——bound 协议的大部分"排序能力"可由接触数/原子数解释。
- **诊断字段确为噪声**：RNA 上 LegacyFull(含 358 个 solver 诊断+坐标)=0.502 < CleanFull=0.561——排除诊断字段后反而更好，证实此前泄漏疑虑。
- **膜任务**：无任何特征组在严格 LOPO 下可泛化；物理+log/nolj 变换也救不了（最好 A1_P__nolj::ridge +0.102）。
- **物理敏感性**：signed-log1p 对树模型逐特征单调 → A1/A7 的 log 版与 raw 完全一致（数学必然）；nolj 在 RNA 上反而略升（0.541 vs 0.529），LJ 通道贡献可疑。

### 一句话归因
**当前 GSPH ~3.7k 特征的有效信息约等于 660 维物理 patch 汇总 + 少量条件性 Hodge 增益；GLMY/路径代数/持久同调的 142 维拓扑读出在本协议下未产生超越物理的可测增量。**
