# 对照基线统一表与论文取舍

## 结论

1. 两个仓库合计出现过 286 条对照记录（约 200 个不同名称，含本方法各消融臂），其中能在"同一批结构、同一候选池、同一切分、同一指标"下与本方法直接比较的只有四组：同图同路径的出生规则对照、离子位点的两两规则与配体质心、FTDMP 蛋白-DNA 上的纯物理特征模型、旧工作区 GSPH7 v3 的同折特征组基线（仅蛋白-DNA 与蛋白-RNA 候选池核验完整）。
2. 正文保留四个内部消融或对照实验（不是外部基线，外部基线见 [EXTERNAL_BASELINE_PLAN.md](EXTERNAL_BASELINE_PLAN.md)），各承担一项论证职责（见第 2 节）：两两支撑滤过、边权距离滤过、两两规则与配体质心、纯物理特征模型。
3. 其余对照删除或放补充材料。外部打分函数（rsRNASP、cgRNASP、FTDMP 官方排序、VoroMQA）目前只有文档里的数字或缺分数文件，不能进正文；膜蛋白、RNA 单链质量评估、深度学习基线和旧排行榜删除。
4. 打分实验在正文只回答"高阶支撑是否提供物理特征之外的判别信息"，不作"方法更优"的卖点：现有证据是整体 Spearman 无显著增量，物理模糊难对上 10 个划分全部为正（均值 +0.018）。

## 2. 正文保留的消融与对照实验（内部，不算外部基线；外部基线见 EXTERNAL_BASELINE_PLAN.md）

原则：同一批数据、同一种切分、同一套指标；每个基线必须回答一个具体问题。

| 正文对照实验 | 论证职责 | 需要补的工作 |
|---|---|---|
| 两两支撑滤过 | 主结论：共同支撑给出两两相容关系表达不了的条形码（同图同路径，差值只来自出生规则） | 用逐路径表在全部 16 结构上重算精确出生值和瓶颈距离（超算任务中） |
| 边权距离滤过 | 说明差异不是"任何几何滤过都会有的"：普通距离滤过与共同支撑的分歧有多大 | 同上，一并输出 |
| 两两规则 + 配体质心 | 离子位点任务的必要性检验：两两规则给不出点，质心给点但不保证同时配位；在难负例层上共同见证点是唯一能排除伪位点的规则 | 全量队列、时间外测集 |
| 纯物理特征模型 `A1_P`（FTDMP 蛋白-DNA bound） | 回答"高阶支撑是否提供物理特征之外的判别信息"：同池、同折、同排序器，主指标用难对成对正确率，宏平均 Spearman 一并如实报告 | 冻结难对检验（`exp06_hardpair_frozen.yaml`）在真实特征表上跑完 |

补充材料：GSPH7 v3 三任务特征组基线（说明物理特征承载绝大部分排序信息，RR 标注候选缺口）；FTDMP 官方排序与 VoroMQA（补齐同池分数后）；rsRNASP PM 对照（统一结构数并入库分数后）；`facetmax`、`shuffled`、`A8_S`、`A9_Pcompact`。

删除：膜蛋白 ΔΔG 全部对照；RNA 单链质量评估全部对照；旧 `fair_summary` 与 `*_ranking.csv` 排行榜；深度学习基线；Dockground 刚体扰动外测；T×H 交互检验（多划分不复现）。
